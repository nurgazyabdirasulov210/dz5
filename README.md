# Hand Portal 🖐

Веб-камера + отслеживание рук (MediaPipe Hands) прямо в браузере. Складываешь «рамку» из пальцев — внутри появляется портал с фильтром.

## Жесты

| Жест | Действие |
|---|---|
| 🤏🤏 Рамка из больших и указательных пальцев обеих рук | портал с фильтром |
| 🖐🖐 Обе ладони раскрыты | следующий фильтр |
| ✌️ 2 или 3 пальца (держать ~0.5 с) | скриншот → папка «Загрузки» |
| 🤚🤚 4 пальца на обеих руках, большой прижат (держать ~0.6 с) | закрепить портал на месте |
| ☝️ Только указательный одной рукой (держать ~0.7 с) | фильтр на весь экран |
| ✊ Кулак (держать ~0.7 с) | убрать закреплённые порталы и фильтр с экрана |

Кольцо в центре экрана показывает, сколько ещё держать жест.

## Клавиши (на ноутбуке)

`Пробел` / `→` — следующий фильтр, `←` — предыдущий, `S` — скриншот, `F` — фильтр на весь экран,
`P` — закрепить портал, `C` / `Esc` — убрать всё, `H` — подсказка по жестам. Клик по картинке — следующий фильтр.

## Фильтры

Сетка, Аниме, Мультфильм, Манга, Неон-линии, Полутон, Поп-арт, Точки, Эхо, Аберрация, Глитч,
Тепловизор, Ночное видение, Негатив, Пиксели, Сепия, Матовое стекло, Микс.

## Запуск

Камера работает только по HTTPS или на `localhost`.

- **GitHub Pages:** Settings → Pages → Source: ветка с `index.html`, папка `/ (root)`.
- **Локально:** `python3 -m http.server 8000` и открыть http://localhost:8000

Всё в одном файле `index.html`, сборка не нужна. Нужен интернет: библиотека и модель рук загружаются с CDN.
